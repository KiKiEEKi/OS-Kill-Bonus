# OS-Kill-Bonus
Получение здоровья за убийство.

Требования:
- Metamod
- CounterStrikeSharp

Переменные:

Файл настроек <OSKillBonus.json> в папке плагина
```json
{
    "Health": 10, //Кол-во здоровья за убийство
    "HealthHS": 15, //Кол-во здоровья за убийство в голову
    "HealthMax": 125 //Макс. кол-во здоровья которое можно получить за убийство
}
```
Установка:
- Закинуть папку <OSKillBonus> в папку </csgo/addons/counterstrikesharp/plugins/>
